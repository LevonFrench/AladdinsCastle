# Original grip hands

`grip-hand-right.glb` and `grip-hand-left.glb` are original parametric glove
meshes, not scans or traced anatomy. Each contains LOD0 (1276 triangles), LOD1
(500 triangles), the four gun materials and five independently driven finger
pivots. Both hands have positive scale. The mirror is authored in the source.

The glove colour is the `[tints]` default in each hand's `.toml` (body `#9eaec2`, accent
`#c4d0dd`); libacvr reads it from there. Body and accent base factors in the GLB are 1.0.

The root is `grip`, at the web of the hand. Units are metres, +Y up, -Z forward,
right-handed; quaternion order is XYZW. The motion tables declare trigger,
grip and primary-button drives and aliases for both detail levels. These are
rigid finger parts rather than a skin or IK rig.

`assembly.json` is generated by `python tools/hand_assembly.py --write` and lists every shipped
gun GLB, including `arc-light-gun`, `funcon` and `con-pointer-remote` (held as a bar, no trigger finger).
Label-anchor bind positions are read from the exported GLB.
`models[id].hands[hand]` attaches the original hand asset to an existing model
node using a local translation and quaternion. For a model with a trigger blade
(not the spade grips or the stick grip), the generator measures that blade in
the exported GLB and sets the translation so the index fingertip rests on the
blade's front face three quarters of the way down. `finger_pose` has per-pivot
translation offsets, rotations and optional positive local scale for the stick
grip. The thumb rotates at its palm pivot; its base is not translated away.
Apply finger motion about its declared parent-frame axis before the rest-pose
rotation, then the positive local scale. The review uses that same order.
`support_grip` identifies
the actual second grip where present. `label_anchors` references actual model
nodes with local offsets and authored bind positions. Bind positions are a
static review aid; a runtime consumer must transform the node and offset after
motion rather than freeze a label at its bind position.

`primary_mount_by_hand[hand]` selects the gun mounting node independently of
the glove's anatomical rest rotation. Place that node at the controller by
applying its inverse world transform to the model root. On the heavy mounted
model, right-primary selects `grip`, left-primary selects `grip_two`.
`support_by_primary[primary_hand]` selects the opposite hand's attachment:
heavy right-primary uses `grip_two`; heavy left-primary uses `grip`.
Prefer that selector over `support_grip`, which retains the right-primary
compatibility default. Shell support uses the canonical dock rotation from
the Wii control policy. These choices do not mirror or rescale a gun mesh.

No existing gun mesh is changed to attach these hands. The CPU review poses
are provisional: they prove export, shading and rigid finger motion, not
physical comfort, controller calibration, gesture recognition or headset fit.

Build with Windows PowerShell 5.1 or newer using `Build-Hands.ps1`, an explicitly
approved existing Blender executable and `-OwnerApprovedCpuBuild`. The script
uses sequential factory-startup CPU processes. `-CheckOnly` needs only Python.
`preview_assembly.py` imports only these authored exports for rest/maximum-drive
side and three-quarter images, using the gun runtime lighting formula.
`make_sheet.py` assembles those renders using an existing Pillow dependency;
there is no automatic installation. Generated meshes and images are CC0;
scripts are GPL-3.0-only.
