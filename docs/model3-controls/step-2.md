# Step 2 — rally and motorcycle
1. Sega Rally 2 reuses wheel/H-gate/pedals and adds a pivoted handbrake and one view button.
3. Each car has six steering/shift choices with its own light/dark vector picture and a single default.
4. Motorcycle bars include a separate twist grip, brake/clutch levers, grip anchors and a rear pedal.
5. Harley defaults to grabbed bars and trigger gas/front brake; A holds rear brake.
6. Thumbstick, optional body lean and realistic twist-throttle choices each have an explanatory card.
7. Exact ports include HandBrake, GearShiftUp/Down, ViewChange, RearBrake and MusicSelect.
8. All five new models were judged from CPU renders; front bars view exposes both levers, and materials/bevels remain distinct.
9. Clutch is visible hardware only: the emulator exposes no Clutch input; no function is invented.
10. The catalog has no flight-stick title, so no flight cabinet is assigned; runtime/controller feel remains untested.
