## Notes
- Strongest injection route for a VR aim ray: move a host OS cursor to the ray hit point in the emulator render window. Used by PCSX2, DuckStation, RPCS3 (via Mouse Handler), Dolphin (bindings), Flycast (SetMousePosition in-process), MAME (mouse provider).
- Strongest structured hook: MAME Lua manager.machine.ioport with absolute IPT_LIGHTGUN ports (write path to verify).
- PINE (PCSX2) is not a gun hook; it only reads and writes game memory.
- Source-level gun counts are not in-game verified.
- GitHub code search quota ran out during this run. Model 2 and TeknoParrot are not source-verified.
