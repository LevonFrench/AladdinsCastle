build helper contained a machine-specific executable path, and route variants
overrode malformed catalog route declarations. Both are corrected within this
lane's files; the existing Hub/detail route tests are unchanged.

`Build-ShellStick.ps1` accepts an explicit existing executable or discovers it on
PATH. Its Windows PowerShell 5.1 check-only path passes; a nonexistent executable
is rejected before application launch. Public privacy regressions and the audit
pass. No Blender, renderer, desktop or headset activity occurred in this repair.

`flat-dolphin` and equal that route's data before selecting an alternate variant.

supports explicit native selection. A new Python regression covers all three
malformed declarations with both selections. Models, previews and profile bytes
are unchanged. Runtime drawing/docking and DSU adoption remain open.

and audit, and five affected Hub/detail/native-controls software suites (68.17 s).
