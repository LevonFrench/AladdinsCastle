## Math and ownership

- `prepare` calls the unchanged fog decision helper once for each original
  triangle vertex, using its integer native depth. The resulting byte weights
  and RGB are values owned by the prepared triangle. Current-eye drawing uses
  those values without decoding CZ again or substituting eye-space depth.
- Homogeneous plane intersections linearly interpolate the unfogged attribute
  with the same edge parameter as position and other attributes. Rasterization
  then divides weighted attributes by the sum of current-eye inverse-W weights.
  This reconstructs the surface attribute after clipping rather than applying
  a second native-depth calculation or screen-linear interpolation.
- Fogged material sampling retrieves neutral palette bytes at brightness 64.
  The interpolated floating shade is clamped per channel to 0..255 before fog
  mixes it with unshaded RGB. Only the final clamped nonnegative value is cast
  to an integer byte, which implements floor without intermediate shade loss.
- The geometry reconstruction, screen-depth interpolation, depth comparison,
  depth write and raycast function are unchanged by this diff. Fog modifies the
  RGB result. Unsupported enabled fog is checked before the CPU target clear.

## Oracle independence and limits

The analytic oracle does not reuse production clipping, raster edge functions,
window barycentrics or inverse-W interpolation. It intersects a pixel ray with
the original reconstructed triangle and derives surface weights independently.
Its ray construction matches the deliberately limited identity-rotation,
X-translated, asymmetric desktop projections used by its three test eyes; it
does not pretend to be a general inverse-view oracle.

The asymmetric fixture puts one original vertex outside the near plane and
uses substantially different scene depths. Expected native weights are fixed
explicitly at 255/127/0 before producer table/depth mutation. Per-pixel checks
use ray-derived surface weights for fog and brightness, with separate depth
expectations; the fixture also requires a substantial difference from
screen-linear weights. Thus the oracle can catch broken clipping/interpolation
without deriving expectations from the raster implementation being checked.

Fixed expectations distinguish full/unfogged endpoints, clamp-before-fog and
preserving `1 * 127.5 / 64` through the fog mix (final byte 6, versus 5 after
premature shade quantization). Additional comparisons cover all written depths,
ray/gun hits, depth-separated occlusion, immutable replay, admission and budgets.
The documented one-byte RGB and 2e-6 depth tolerances are software test bounds,
not measured driver errors. Constant texels isolate the new fog math; material
sampling itself belongs to the separately reviewed material block.
