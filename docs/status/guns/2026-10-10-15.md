## Diagnosis and independent repro

A compile-time type assertion confirms that `std::tan(.7f)` returns float.
Assigning that result to double preserves the premature float rounding. The old
endpoint check therefore measures the packed matrix against rounded slopes,
which can differ materially from the requested angular endpoints in a thin FOV.

The probe independently reproduces the defect on Windows MSVC without needing
the reported Linux outcome. At original head 500280f, the adjacent pair
`1.2f, nextafter(1.2f,2.f)` is accepted for both GL and Vulkan. Reconstructing
the requested angles with double tan gives X NDC endpoints
**-0.81975805573165417 / 1.0842339871451259**, outside the unchanged 0.0001
tolerance. The .25, .5, .7 and .9 pairs reject atomically on this compiler.

For the specific .7 pair, actual input floats are .69999998807907104 and
.70000004768371582. Double slopes are .84228836008485097 and
.84228846197599716. The formula's packed float scale/offset are 19628790 and
16533103, yielding **-1.6604500785470009 / .3395498339086771**. These coefficients
fail the requested endpoint precision by a wide margin, supporting rejection of
this particular constructed matrix. Adjacent input values alone are not a
general rejection rule.

An isolated one-ULP slope sensitivity calculation also shows why the old
self-check is insufficient: a perturbed float-slope pair can reconstruct -1/1
against itself, yet map the requested double-tan angles to approximately
-1.248571/.460879. This is a numeric sensitivity example, not a claim about the
exact Linux library outputs.

## Corrected exact-head result and test contract

At exact head c36ae72, explicit double tan arguments eliminate the early slope
rounding. The independent probe finds **zero contract failures** across the five
adjacent pairs .25/.5/.7/.9/1.2 under both GL and Vulkan: all ten reject with
BAD_ARGUMENT and leave the complete seeded destination unchanged. The original
.7 angular case and the preceding GL near=1/adjacent-far case also reject
atomically. No tolerance was relaxed.

The lead's added `thin_frustum_admission` test expresses the correct contract:
if accepted, reconstruct the requested angles from double tan and require the
packed matrix endpoints within 0.0001; otherwise require atomic BAD_ARGUMENT.
This avoids assuming every thin frustum must reject. The older specific .7
rejection assertion remains supported by the numeric receipt above. No further
actionable defect was reproduced within this bounded scope.
