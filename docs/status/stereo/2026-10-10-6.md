## Deferred rendering semantics / gates

Super22 orders palette/shade → CZ fog → polyfade; System22 supports fog before
shade (`quad_gl.h:36`). Original native depth must stay distinct from eye depth;
vertex versus per-fragment CZ interpolation and clipping need an explicit policy.
GL remains unsupported for newly enabled fog until a later draw stage is tested.

`ss22_gl.c:61-67` uses mixer bytes0..2 for polyfade, disabled only when all three
are255; an enabled255 channel multiplies by255/256. Generic `quad_gl.c:794-827`
folds fade into float vertex colour before its combiner/clamp, while the documented
pixel-chain order places it after shade/fog. Over-bright saturation/rounding parity
must be chosen explicitly before a new fade draw, rather than claimed source-exact.

`ss22_gl.c:517-533` screen-fades polygons/sprites/background with mixer bit0 and
nonzero factor, using `(factor+1)/256`, then draws text, then whole-frame gamma.
`text_hw.c:99,152-155` uses bit1 and a different `/255` blend. Sprites also have
their own fade gate (`sprite_hw.c:294-309`). `post_gl.c:1-14,133` gamma operates on
the composed image; pre-baking a palette cannot substitute for that stage.

`quad_gl.c:215-227` sorts decreasing native zsort, equal depths by decreasing
emission order. `ss22_gl.c:510-514` merges 24-bit polygon/sprite z with sprites
first on ties. Shared depth for guns does not supply native painter/text priority.
These changes require layer/priority admission before implementation.
