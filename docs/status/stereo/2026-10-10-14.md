**Ownership/integration:** `SceneInput` owns `CompositionPlan`; `prepare`
copies into `Frame` through staging/lease publication. Own mixer,
item identities/native24-bit priorities/emission order and prioverchar/item-fade
flags. Absent plan preserves current polygon-only draws. Present complete-plan
requests return UNSUPPORTED in existing GL draw **before upload/clear** until supported.

**CPU/order contract:** private `compose_cpu_frame(lease, eye, owned_eye_spans, out)`
validates tick, eye/pose, identities and explicit complete/empty layer declarations.
Colour-stage tags require polygon post-shade/fog/polyfade, sprite post-fog/pre-own-fade,
text pre-own-fade with resolved source alpha: no omitted/double fade/gamma. Background
→ priority-merged polygon/sprite items (sprite own fade before alpha) → screen fade
→ text own fade/masked alpha → LUT. Missing modes/layers or ambiguous sprite ties
reject. Physical depth cannot infer native priority; flattened world colour
cannot interleave sprites between polygons. Keep items/gun depth separate.

**Now/wait:** implement this CPU contract with explicit floor checkpoints and byte
LUT indexing. <=64 items/64x64 are fixture budgets, not native capacity. Native
decoding, spot/shade modes, anchors, actual ordering and depth interaction await
the adapter; stale-pose spans/unsupported modes reject.

**Discriminating oracle:** world100/fade20/factor127 gives60 before text200.
Nonlinear LUT entries L60=7/L200=19/L110=23 distinguish final gamma and text
ordering: uncovered7/text19, not screen-faded-text23. Text alpha128 over60 floors
to130; L130=29 differs from blending gamma-first inputs19/7 to13. Black fade with
factor1 maps white world/sprite to253 but independently faded white text to254.
Sprite own-plus-global fade yields251, not253: cover flags0/1/2/3 and item flags. Add
polygon/sprite tie overlap, prioverchar on/off/transparent coverage, zero-factor
bypass, gamma presence, ownership/eye-neighbours. Retain fractional fog witness
318/255→1 versus premature-floor254/255→0 when touching the colour pipeline.

**Later GL strategy:** finalize only after all declared game layers, before runtime
guns. Copy the eye's game colour into one budgeted private scratch texture; read
it and a nearest256x1 RGB LUT when writing back, avoiding attachment feedback.
Keep shared depth untouched (no clear/writes), scope scissor, preserve alpha and
restore FBO/program/texture/sampler/clamp/blend/unpack state; owner cleanup/replay
budgets need mocks. Avoid native whole-window/state assumptions. GL integration
waits for complete inputs. No ABI/factory/native admission, board expansion,
GPU/context/native execution, game/generated/BIOS or SDK/install/download scope.
