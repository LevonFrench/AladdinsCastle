## Exact source gates and recommended policy

Authority: generic `namco22-decompile` pin
`a9f1a0a1f9de62387a7138006fa36933fd477123`. `fog_hw.c:168-169` copies mixer
bytes0..2 and enables polygon fade unless **all three** equal255.
`ss22_gl.c:61-67` applies it only when mixer state is valid and that global enable
is set. Enabled channel factor is **byte/256**, including a255 channel. All255 is
disabled identity, not three255/256 factors. Screen-fade flag/factor and CZ fog
gates do not gate polygon fade. `ss22_gl.c:498-501` supplies the fade callback for
the Super22 shade-then-fog configuration.

Recommend an explicit private **Super22InputFold** policy with copied tick/three
bytes and derived enable, separate from fog/background. Absent means identity.
Decode only existing owned mixer bytes0..2 with exact length/nonzero tick checks;
bind to the same immutable Frame. Preserve raw fog RGB and fade bytes; do not
pre-quantize their scaled values into byte fields.

`quad_gl.c:824-827` multiplies each primary shade RGB input by its factor before
unit0 texel modulation/RGB_SCALE4/clamp. `quad_gl.c:748` separately scales fog
constant RGB before unit1 interpolates. `quad_gl.c:136-156` consumes those inputs
in Super22 mode2. Thus this pin folds fade **before shade saturation**, into both
shade and fog inputs, despite its comment describing the conceptual fade-after-fog
chain. Copy this explicit source policy; do not claim hardware/order parity.

For channel texel T, interpolated brightness B, original unfogged weight A,
raw fog channel F, and D=1 if absent/disabled else byte/256:

```
S = clamp(T * B/64 * D, 0, 255)
out = floor(clamp(S * A + (F * D) * (1 - A), 0, 255))
```

GL primary RGB becomes brightness/256 times each D, with RGB_SCALE4 and the
accepted explicit fragment clamp. Fog constant becomes raw F/255 times D.
Alpha, native weights, palette bytes, background clear and shared depth stay
unchanged. CPU retains float inputs through the final floor. Constant per-frame
factors commute with current-eye clipping/interpolation; no new pass/unit/resource.

## Hand-computable order discriminators

Unless stated otherwise: T=200, B=128, F=40, A=127/255; values below are final floors.

| Case | Proposed input fold | Competing order that must fail |
| --- | ---: | --- |
| enabled fade byte128, D=1/2 | **109**, from (200*127 + 20*128)/255 | Fade after the already-clamped shade/fog result: **73**; fading shade only, leaving fog unscaled: **119**. |
| enabled fade byte192, D=3/4 | **142**, from (255*127 + 30*128)/255 | After-clamped-result fade: **110**; skipping shade saturation until final output: **164**. |
| all channels255, T=64/B=64/A=1 | **64**, disabled identity | Applying255/256 despite the all255 disable gate gives **63**. |
| RGB bytes(255,128,255), red T=64/B=64/A=1 | red **63**, floor(64*255/256) | Treating each255 channel as identity despite another channel enabling fade gives **64**. |
| T=1/B=127.5/F=10/A=127/255/byte128 | **3**, exact39245/13056 before floor | Premature integer shade yields **2**. |

Also test full fog A=0 (F scales), no fog A=1 (shade scales), zeros (covered RGB
black while depth/opaque alpha remain), mixed channels and unchanged uncovered
background. Use independent rational expectations, not the production sampler.

## Admission, dependencies and later stages

After PR24 acceptance, use a new dependent branch and commit this proposal there.
Admit active fade only for explicit opaque textured Super22 World polygons,
objectflags0, with absent fog or the accepted Super22 table policy. Reject active
fade on retained HUD/backdrop/GunFlash, flat/solid material, System22 constant fog,
unknown policy or bad tick/bank length before upload/clear. Never skip fade on an
unsupported polygon. Inactive/absent fade retains prior admission/pixels; an empty
world leaves background untouched. Existing synthetic GunFlash discard stays explicit.

Screen fade, sprite/text gates and final gamma remain separate deferred stages;
this polygon-only policy cannot admit a request for complete composed-screen
processing or native Time Crisis. Production graphics/native admission stays zero.
Tests: cases above, asymmetric clipped/moved-eye scenes, ownership/replay, both
fog gates without disabling fade, invalid/unsupported atomic rejection, unchanged
depth/raycast/background, hostile state/cleanup and strict CPU/mock/source checks.
No other board, shared ABI, native factory, GPU, game/generated-source/BIOS access,
install/download or broad research scope.
