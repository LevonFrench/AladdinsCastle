## Recommended bounded implementation

Add actual Super22 fog to explicitly textured, opaque World triangles through
the existing compatibility GL draw path, plus an independent CPU reference.
Time Crisis is `namco-super-system-22`; System22 constant fog, solid objects,
flat-colour triangles, backdrop, HUD and sprites remain outside this first stage.
Reject unsupported *enabled* fog combinations before any target clear/upload;
validated all-unfogged metadata may retain the existing draw behavior.
No shared ABI or board factory expansion. Native game admission stays zero.

Use the pinned generic `engine/quad_gl.c:88-197` Super22 two-unit combiner shape:
unit 0 shades the material, unit 1 interpolates that result toward fog RGB.
This produces fog during the same primitive draw as its colour/depth, avoiding
an extra overlay pass with ambiguous equal-depth coverage. Preserve opaque
output alpha from the material; vertex alpha carries the unfogged weight and
never becomes transparency or a native priority value.

## Packet, interpolation and clipping

Prepare immutable three-vertex unfogged weights `a[k] = decide_fog(...).alpha/255`
and RGB from the PR21 owned frame state once per lease. Decisions consume original
integer native depths and CZ gates/bank/delta only. Moving eyes never substitute
eye-space depth, modify the table, reread a snapshot or redo native emulation.
No per-fragment CZ lookup is claimed.

For each current-eye draw, interpolate those weights with the current eye's
perspective-correct primary colour interpolation. The CPU reference must carry
the weights through homogeneous clipping and interpolate them using new-eye
inverse W, alongside existing UV/brightness attributes. Hardware clipping must
interpolate the supplied weight; do not decode CZ at a newly generated eye clip
vertex. Native near-clipped fan vertices must already carry their copied depth
metadata. This is an explicit stereo extension of the generic renderer's
per-native-vertex alpha approximation, not verified native pixel parity.

## Saturation and composition

For the admitted textured path, propose the following normalized RGB reference:

```
S = clamp(texel * brightness / 64, 0, 1)
A = perspective_interpolate(a[0], a[1], a[2])
out = S * A + (fog_rgb / 255) * (1 - A)
```

Unit 0 retains the existing RGB_SCALE=4 shading and its intermediate clamp;
unit 1 uses RGB_SCALE=1 and PRIMARY_COLOR alpha for interpolation. Fog colour
is unshaded. Include a high-brightness case that distinguishes this rule from
clamping only after fog. Specify CPU byte rounding separately and bound the
CPU/mock comparison tolerance; do not declare exact GL driver quantization.

Polygon fade, screen fade and final gamma are three separate later composition
operations. Do not bake them into fog RGB, palette or brightness here. In the
pinned native code polygon fade is folded into combiner inputs; treating it as
an after-clamp operation would require additional evidence. This proposed
no-fade/no-gamma packet cannot admit complete Time Crisis composition.

Retain the current eye's one clear, LEQUAL depth test and world depth writes.
Fog changes RGB only; the runtime's shared gun depth and raycast geometry remain
unchanged. Preserve existing explicit triangle order. Native polygon/sprite
priority merging, tie breaks, coplanar semantics and priority-alpha are not
reconstructed by fog; synthetic depth-separated fixtures cannot prove those.

## GL ownership and checks

One private complete one-pixel texture on unit 1 is sufficient for this slice.
Count it in the existing texture/budget plan, create before clear, reuse across
both eyes/replays and delete with the owner's frame lease. Do not create a
context or retain/delete borrowed attachments. Extend the state guard to unit 1
binding, sampler, texture environment/constant RGB and matrix, restoring its
hostile incoming state and the original active unit on success and failure.
All texture units need the existing canonical disable policy. Unsupported
capabilities or fog layers fail atomically before drawing. No per-triangle
allocations or extra private resource lifetime beyond the lease.

Synthetic CPU/mock tests should prove:

- No/full/partial fog endpoints, table gates, selected banks and same-tick binds.
- Saturated shade before fog; fog RGB unaffected by brightness; opaque alpha.
- Asymmetric triangles, near-plane clipping and perspective interpolation against
  an independent analytic reference; original native depth differs from scene Z.
- Moved eyes and repeated poses reuse the same native fog weights/resources;
  new-eye perspective changes interpolation without changing native decisions.
- Colour changes while written depth, geometry/raycast and shared target
  attachment identities remain identical; front/behind synthetic occlusion.
- Mixed unfogged/fogged switching, hostile unit-1 state, missing dispatch,
  allocation/upload/draw failures and exactly-once owner-thread cleanup.
- Unsupported enabled fog cases reject before clear; explicit absent policy
  keeps prior synthetic draw results.

Run strict MSVC pinned-source and installed GCC CPU suites plus privacy audit.
No GPU/context, game/generated source/BIOS access, SDL SDK, install, download,
headset or Steam writes. Those remain owner-approved gates. Lead approval of
this proposal would authorize code/CPU mocks only, not those external gates.
