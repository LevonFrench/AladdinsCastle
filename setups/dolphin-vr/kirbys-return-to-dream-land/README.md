# Kirby's Return to Dream Land mono theatre option

This optional fragment keeps the original HUD layout in a flat theatre view. Merge its two VR values into a separate test user's configuration; it is not installed automatically and does not move individual gear-counter draws.

E2: the equivalent command-line values were tested at 1x, single-core, in Stage 1-1. Movement, a jump and star collection were visible; an independent checkpoint restore repeated movement and jumps with the three gear slots, lives, stars and health display intact. The earlier gear-specific relocation remains rejected. Native rendering in this stage, sustained 3x/MSAA 4 pacing and headset acceptance are unverified.

The offline route explicitly preloads `AC Pad Sideways`; right-primary must report Wii 2. See the [staged entry replay](../motion-controls/input-probe/kirby-rtdl-round2-enter-stage.txt) and [resume replay](../motion-controls/input-probe/kirby-rtdl-round2-resume.txt).
