# DKCR mono theatre option

This optional fragment keeps the ordinary game camera in a flat theatre view. Merge its two VR values into a separate test user's configuration; it is not installed automatically and contains no quality or input changes.

E2: the same values were tested as command-line overrides at 1x, single-core, using the private level 1-1 checkpoint and an independent restore. The world and hearts were readable where the expanded native view clipped badly. One capture was dominated by a close-up banana bunch; its cause was not isolated. This is a limited viewing option, not complete rendering or headset acceptance.

Use the `AC Pad DKCR` profile and explicit `Wiimote.Wiimote1.Source=1` for its grip-shake route. See the [boot replay](../motion-controls/input-probe/dkcr-round2-play.txt) and [resume replay](../motion-controls/input-probe/dkcr-round2-resume.txt). Sustained 3x/MSAA 4 pacing and live controls remain unverified for this option.
