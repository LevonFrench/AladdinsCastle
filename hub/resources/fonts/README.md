# Fonts

Archivo, by Omnibus-Type (Héctor Gatti and the Archivo Project Authors),
<https://github.com/Omnibus-Type/Archivo>, version 2.001, under the SIL Open
Font License 1.1 (`OFL.txt`, beside this file). The license declares no
Reserved Font Name.

The three files are static instances of the upstream variable font at normal
width, weights 500 (Medium), 700 (Bold) and 900 (Black). Their name tables were
set so the three share one family, "Archivo", told apart by weight. The glyphs
are unchanged. They are built into the Hub as resources and loaded at start,
so the Hub needs no font installed and downloads none.
