Privacy

This site does not track you. It has no analytics, no cookies, no ads, no forms and no account. The project does not collect or keep anything about visitors.

What stays on your device

The music bar remembers a few small settings in your browser, and nothing else does:

  • the volume you set (kept in local storage until you clear site data);
  • whether you stopped the music and where the track was, so it carries over between pages (kept in session storage, which the browser drops when the tab closes).

None of this is sent anywhere. The music file is only downloaded after you press Play or first click on the page, never before.

Outside services the site still uses

Every page request reaches a server run by someone else. That server sees your IP address and browser details, as any web server does.

ServiceUsed forWhat it sees
Cloudflare PagesHosting every file on this site.Your IP address and the usual request details, in its own server logs. The project adds no analytics script of its own.
jsDelivr (cdn.jsdelivr.net)Serving the Three.js library for the 3D arcade page (index.html only).Your IP address and browser details when that page loads. The other pages do not contact it.
GitHubLinks to the source code.Nothing, unless you follow a link; then GitHub's own privacy policy applies.

The fonts are served from this site, so no font provider is contacted. The 3D models, the ASCII animations and the music are served from this site too.
